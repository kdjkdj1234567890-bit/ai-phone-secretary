# 📞 AI 전화비서 — 이제는 일하는 동안 전화 걱정 안 해도 돼요

사장님들은 못 받은 전화에 자책합니다. "그 전화 받았으면…" 하는 후회.
이 데모는 그 후회를 없애주는 것이 목표입니다.
**이제는 일하는 동안 전화 걱정 안 해도 돼요.** AI 비서가 못 받은 전화를 먼저 받아
손님을 편하게 맞이하고, 예약까지 받아둡니다.

"놓치고 있던 돈을 찾아주는 시스템" 시리즈 1번 · 9개 중 플래그십.

## 타겟 고객
개발자가 아닌, **돈을 쓰는 동네 사장님** — 청소·미용실·이사·용달처럼
"일하느라 전화를 못 받는 시간"이 곧 "마음이 불편한 시간"인 분들.
이 데모는 사장님 말로만 설명합니다. 개발자 용어(인텐트·파이프라인·API·자동화 등)는 화면에 쓰지 않고,
"편하게", "안심", "걱정 마세요"라는 말을 씁니다.

## 실행 방법
```bash
cd 07-missed-call-ai
./run.sh
```
브라우저에서 `http://localhost:5007` 로 접속하세요.

- `./run.sh` 하나로 실행됩니다. (Flask가 없으면 자동 설치)
- **5007번 포트가 이미 사용 중이면 5008, 5009… 순서로 비어 있는 포트를 자동 탐색**해 실행하고,
  실행된 주소를 화면에 표시합니다. (`PORT=5009 ./run.sh` 처럼 직접 지정도 가능)
- 데이터는 폴더 안의 `demo.db`(SQLite)에 저장됩니다. 처음 실행하면 예시 문의 3건이 들어 있습니다.
- 멈추려면 `Ctrl+C`.

## 1분 체험 코스
1. **첫 화면** — "청소 중 전화 3통을 놓쳤습니다. 그중 2명은 경쟁업체에 예약했습니다."라는
   짜증 모먼트 오프닝으로 시작합니다. 사장님의 실제 하루를 재현한 뒤,
   "이제는 전화 걱정 없이 일하세요"로 이어집니다.
2. **💰 이 돈은, 이제 놓치지 마세요** — "어제 못 받은 전화 N통 × 1건당 평균 매출"을 넣으면
   AI 비서가 지켜줄 매출이 바로 계산됩니다.
3. **🏪 어떤 가게세요?** — 청소업체 / 미용실·네일샵 / 이사·용달을 고르면
   AI 비서의 말투·가격표·예약 방식이 그 가게에 맞게 바뀝니다.
   - 청소업체: 평수별 가격 안내 + 무료 방문 견적
   - 미용실·네일샵: 시술별 가격·소요시간 안내 + 디자이너 지정 예약
   - 이사·용달: 간이 견적(평수·거리 입력) 후 전화 상담 연결
4. **🎬 핵심 시나리오 자동 시연** — 청소 중인 사장님 → 전화 옴 → AI가 받음 →
   손님 "입주청소 30평이요" → AI가 평수별 가격 안내 + 예약 잡음 →
   "이 손님은 어제 같으면 경쟁업체로 갔을 손님입니다". 사장님은 마음 편히 일만 하세요.
5. **📵 부재중 전화 체험** — 직접 손님 역할로 전화·문자를 체험합니다.
6. **💬 카톡 스타일 채팅** — 사장님이 매일 쓰는 말풍선 화면. "가격 얼마예요?",
   "방문 견적 가능해요?", "예약할게요"라고 물어보세요.
7. **👔 사장님 화면** — 전화 걱정 없이 일하신 오늘, AI 비서가 챙긴 일을 확인합니다.
   "AI 비서가 지켜준 예상 매출"을 보여줍니다.
   - 🔥 경쟁 FOMO: "같은 동네 청소업체 N곳이 못 받은 전화를 AI로 잡고 있습니다"
   - 📈 이번 달 리포트 자동 생성: "이번 달 AI가 잡아낸 전화 ○통, 지켜낸 매출 ○○만원" + "동네 평균 대비 ○%"
8. **☀️ 사장님 오늘 브리핑** — 아침 도파민 대시보드.
   "오늘 AI가 받은 전화 N통, 잡은 예약 M건, 지켜낸 매출 ○○만원" +
   벤치마크 "우리 동네 청소업체는 못 받은 전화의 70%를 AI가 잡아냅니다. 사장님은요?"
9. **⚙️ 가게 설정** — 가게 이름·업종·가격표·자동 문자를 바꿀 수 있습니다.
   - 🎁 추천 리워드: "옆 가게 사장님께 소개하면 둘 다 1개월 무료" — 소개 링크 만들기
   - 📈 성장 시뮬레이터: 월 소개율 슬라이더 → 1년 후 가게 수 그래프

## 🌱 왜 만들었는가
- **날짜**: 2026-10-12
- **이유**: 대한민국 자영업자 500만 명 중 90%가 5년 안에 문을 닫습니다. 이유는 실력이 없어서가 아니라, 혼자서 다 하다가 지쳐서입니다. 못 받은 전화 1통은 그 자리에서 경쟁업체로 넘어가는 손님 1명 — 되돌릴 수 없는 손실이 매일 발생합니다.
- **누구를 위해**: 일하느라 전화를 못 받아 자책하는 동네 사장님. "그 전화 받았으면…" 하는 후회를 없애드리기 위해.
- **철학**: 높은 가치는 느끼는 사람들에게. 우리는 사장님의 일을 세상이 알아주게 만듭니다.

## 핵심 메시지 (사장님께 드리는 말)
- **"이제는 일하는 동안 전화 걱정 안 해도 돼요."**
- "그 전화 받았으면…" 하는 후회, 이제 그만하세요.
- 못 받은 전화가 와도 AI 비서가 1초 만에 편하게 맞이합니다.
- 단골 질문("가격 얼마예요?")에는 가게 가격표대로 정성껏 답합니다.
- 예약까지 받아두니, 사장님은 일 끝나고 편하게 확인만 하세요.
- 손님 응대는 이 프로그램 안에서 직접 처리되고, 외부로 전송되지 않으니 안심하세요.

## 기술 메모 (개발자용)
- Python Flask + SQLite, 한국어 UI, 모바일 반응형.
- 손님 말 알아듣기: 규칙 기반(예약 흐름·서비스명·날짜/시간/전화번호 읽기) + TF-IDF 말뭉치 유사도 매칭. 외부 LLM·SMS API 사용 안 함.
- 테스트: `python3 test_e2e.py` (70개 항목 — 전체 페이지 200, 부재중→응대→예약 E2E, 업종별 시나리오, 대시보드 반영).
- 스크린샷: `screenshots/` (데스크톱 + 모바일).
